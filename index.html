How the WhatsApp connection works

Option A — WhatsApp Web + extension (₹0, uses your normal number)
  • Nothing to give anyone: no API key. The extension opens each chat in your logged-in WhatsApp Web tab, attaches the image, types the caption and presses Send — the same as you doing it by hand.
  • Data stays on your computer (Chrome extension storage). This page never uploads your contacts in this mode.
  • Risk: WhatsApp does not officially allow automation of personal/Business-app accounts. Low, human-like volume to people who know you is usually fine; cold lists, identical texts and many “block/report” taps get numbers banned. Use a number you can afford to lose while you test.
  • Safe-ish habits: new number → start 10–15/day for a week, then 25–40; keep gaps ≥ 8 min; vary wording with {a|b}; include the person's name; honour STOP replies.
Option B — Official WhatsApp Cloud API (what to create and give)
  1. Go to developers.facebook.com → Create app → type Business → add product WhatsApp.
  2. In WhatsApp → API Setup: add your business phone number (it must not be active on the WhatsApp app — use a new SIM or delete WhatsApp from that number first) and verify it by OTP. Copy the Phone number ID.
  3. Business Settings → System users → create an admin system user → Generate token with permissions whatsapp_business_messaging, whatsapp_business_management (choose “never expire”). That is your WA_TOKEN.
  4. WhatsApp Manager → Message templates → create a Marketing template (optional image header, body like “Hi {{1}}, …”). Wait for approval.
  5. Add a payment method in WhatsApp Manager (needed for marketing messages).
  6. In this GitHub repo → Settings → Secrets and variables → Actions → add secrets: WA_TOKEN, WA_PHONE_NUMBER_ID, CAMPAIGN_KEY (any long passphrase — type the same one above).
  7. Build your schedule here, then “Encrypt & push”. The GitHub Action runs every 10 minutes and sends what is due.
